# AET GO – דמו למערכת ניהול מסעדות

דמו עובד של AET GO, מיועד להצגה למשקיעים ולמסעדות. כל המסכים מחוברים לאותו מסד נתונים ומתעדכנים זה מול זה בזמן אמת (polling כל 2 שניות).

> ⚠️ זה דמו ולא מוצר סופי. אין תשלומים אמיתיים, אין NFC אמיתי ואין חיבור לרשות המסים. כל התשלומים, הקבלות, ההודעות והזמנות הסחורה מדומים.

## הרצה

צריך Node.js 20 ומעלה.

```bash
npm install && npm run dev
```

אחר כך פותחים את http://localhost:3000.

- בהרצה הראשונה נוצר אוטומטית מסד SQLite בקובץ `data/aetgo.db`, עם נתוני דמו: מסעדה אחת ("ביסטרו הנמל"), 12 שולחנות, 25 מנות, כ-150 חברי מועדון, 8 עובדים, מלאי, ספקים ושליחים.
- **איפוס דמו:** הכפתור "↺ איפוס דמו" במסך הבית או בלוח המנהל מחזיר את כל הנתונים למצב ההתחלה. מומלץ ללחוץ עליו לפני כל הצגה.
- **הצגה מכמה טלפונים:** כדי שטלפונים באותה רשת יוכלו להתחבר, מריצים `npm run dev -- -H 0.0.0.0` ונכנסים לכתובת `http://<IP-של-המחשב>:3000/t/5`.
- **"טלפונים" במחשב אחד:** כל לשונית בדפדפן נחשבת לטלפון נפרד, כך שאפשר לפתוח את `/t/5` בשתי לשוניות ולקבל שני סועדים באותו שולחן.

## מסלול הצגה מומלץ (כ-7 דקות)

1. **מסך הבית `/`**: לוחצים "איפוס דמו" ומציגים את רשימת המסכים.
2. **שולחן `/t/5`**, בשתי לשוניות או בשני טלפונים:
   - "נגיעה במדבקת NFC": כל סועד מקליד שם ומצטרף לשולחן.
   - מזמינים מהתפריט. אפשר לסנן לפי טבעוני, צמחוני, ללא גלוטן או ללא אגוזים, ולפתוח מנה כדי לראות רכיבים ואלרגנים. שולחים למטבח.
   - בלשונית **"חשבון"** רואים את החשבון המשותף. כל מנה רשומה על שם מי שהזמין אותה.
   - בלשונית **"שאלו אותנו"** נמצא הצ'אטבוט (בלי AI). שאלות לדוגמה: "יש אגוזים במלבי?", "מנות עיקריות עד 70 ₪", "מה טבעוני?", "האם המסעדה כשרה?", "איפה חונים?". על שאלה שהבוט לא מכיר ("יש לכם משחקי קופסה?") הוא עונה "אשאל את המלצר", והקריאה מופיעה בטאבלט המלצר.
   - **💳 מועדון**: הצטרפות בלחיצה אחת, עם תיבות אישור לדיוור ולמיקום. אפשר גם להזדהות כחברה קיימת עם `050-1234567` (דנה: אלרגית לאגוזים ולבוטנים, ויום ההולדת שלה בעוד יומיים). אחרי ההזדהות מנות עם אלרגנים מסומנות לה באדום בתפריט.
3. **מסך מטבח `/kitchen`**: ההזמנות מסודרות לפי זמן, עם טיימר שמשנה צבע (ירוק, כתום, אדום), הערות למטבח והתראות אלרגיה של חברי מועדון. לוחצים "✓ מוכן".
4. **טאבלט מלצר `/waiter`**: השולחן הופך לירוק "מוכן להגשה!". לוחצים עליו ורואים:
   - כרטיס חבר מועדון (בשולחן 2 יושבת דנה), עם אלרגיות, אירועים והזמנה קודמת.
   - הוספת הזמנה על שם סועד מסוים, ופיצול חשבון: "שלו", "שווה" או "פיצול ל-N".
   - פתיחת שולחן פנוי. שולחן 11 שמור לארוחה מתוכננת.
5. **חזרה לטלפון → "לתשלום"**:
   - בוחרים אימוג'י. 😡 או 😕 שולחים **התראה מיידית ללוח המנהל**. 🙂 או 😍 מציגים כפתור לביקורת בגוגל.
   - בוחרים "מה שהזמנתי" או "חלק שווה", טיפ, ואמצעי תשלום (כרטיס, Apple Pay, Google Pay או ביט).
   - כשכל הסועדים שילמו, השולחן נסגר אוטומטית ומוצג מסך תודה.
6. **לוח מנהל `/admin`**:
   - מכירות היום, שולחנות פתוחים, ממוצע לעסקה, שביעות רצון ובאנר אדום על משוב שלילי.
   - **"המסעדה ממלאת את עצמה"**: התפוסה מושווית לתפוסה הרגילה ביום ובשעה האלה. כשהיא נמוכה מוצגת הצעה לשלוח הטבה לחברי מועדון קרובים. בוחרים רדיוס והטבה ולוחצים "שליחה" (השליחה מדומה).
   - **צ'אט בסגנון וואטסאפ** עם פקודות קבועות: `כמה מכרתי היום`, `מי איחר החודש`, `תזמין 10 עגבניות` (ההזמנה מופיעה מיד במסך המלאי), `מה חסר במלאי`, `כמה שולחנות פתוחים`.
7. **שאר המסכים**, לפי הזמן שנשאר:
   - **קופה `/pos`**: מכירה מהירה, קבלה מדומה עם פירוט מע"מ, ו"סגירת יום (Z)".
   - **הזמנה אונליין `/order`**: בוחרים משלוח או איסוף, משלמים (בתשלום מדומה) ועוברים לעמוד מעקב שמתעדכן לבד.
   - **משלוחים `/delivery`**: לוח בסגנון קנבן. משייכים שליח, וכשהמטבח מסמן "מוכן" מעבירים ל"יצא לדרך" ואחר כך ל"נמסר". עמוד המעקב של הלקוח מתעדכן בהתאם.
   - **משמרות `/staff`**: החתמת כניסה ויציאה עם זיהוי איחורים, סידור עבודה שבועי שאפשר לערוך, ודוח שעות עם ייצוא ל-CSV.
   - **ניהול עובדים `/team`**: מוסיפים עובד/ת (שם, תפקיד, שכר לשעה, טלפון ושולחנות באחריותו/ה). כל עובד/ת מקבל/ת **2 קישורים אישיים**, ואפשר לשלוח את שניהם בוואטסאפ בלחיצה:
     - **טאבלט מלצר אישי** `/waiter/<קוד>`: מציג רק את השולחנות שלו/ה ואת הקריאות מהם, בלי גישה לשאר המסכים.
     - **פאנל אישי** `/me/<קוד>`: החתמת כניסה ויציאה, סידור העבודה השבועי שלו/ה, דוח נוכחות, ומשכורת החודש (שעות רגילות, שעות נוספות, חלק בטיפים, ברוטו), וגם החודש הקודם.
     - אפשר להשבית עובד/ת או ליצור קישורים חדשים. הקישורים הישנים מפסיקים לעבוד מיד.
     - קישורים קבועים לדמו: נתנאל (שולחנות 1–4) `/waiter/n3x9pw` ו-`/me/n3x9pw`, ליהי (שולחנות 5–8) `/me/l5r8tz`.
   - **משכורות `/admin/payroll`**: טבלת שכר לכל העובדים לחודש הנוכחי ולשני החודשים הקודמים. כוללת שעות, שעות נוספות (125% ו-150% אחרי 8 שעות במשמרת), חלוקת קופת הטיפים בין המלצרים לפי שעות, ברוטו וסימון "שולם". לחיצה על שורה פותחת את פירוט המשמרות, ויש ייצוא ל-CSV לרואה החשבון. החישוב מדומה, בלי ניכויים.
   - **מלאי `/inventory`**: כל מכירה מורידה מלאי לפי מתכון, ומלאי נמוך מסומן ונשלחת עליו התראה. אפשר להזמין סחורה מספק ולסמן "קבלת סחורה".
   - **מועדון `/club`**: רשימת חברים, נקודות, דרגות והטבות, וכרטיס חבר AET GO בעיצוב של כרטיס בארנק דיגיטלי.
   - **ארוחה מתוכננת `/plan/NOA30`**: קישור קבוצתי שבו כל אחד בוחר מנה ומשלם מראש. ההזמנה נכנסת למטבח אוטומטית בשעה שנקבעה. לצורך ההדגמה יש כפתור "שליחה למטבח עכשיו". ב-`/plan` אפשר ליצור ארוחה חדשה.

## מבנה הקוד

| נתיב | תוכן |
| --- | --- |
| `lib/seed.ts` | נתוני הדמו: תפריט, מלאי, מתכונים, עובדים, חברי מועדון והזמנות מוקדם יותר היום |
| `lib/db.ts` | חיבור ל-SQLite, סכמה ואיפוס |
| `lib/logic.ts` | כל הלוגיקה העסקית: חשבון ופיצול, מטבח, מלאי, מועדון, צ'אט הבעלים ועוד |
| `lib/chatbot.ts` | צ'אטבוט הסועדים, מבוסס חוקים ובלי AI |
| `app/api/state` | נקודת קריאה אחת לכל מסך (`?view=...`) |
| `app/api/action` | נקודת כתיבה אחת לכל הפעולות |
| `app/*` | המסכים (Next.js App Router, TypeScript, Tailwind) |

הסנכרון בזמן אמת נעשה ב-polling כל 2 שניות (`usePoll` ב-`lib/client.ts`). בנוסף, כל פעולה מרעננת מיד את המסך שביצע אותה.
